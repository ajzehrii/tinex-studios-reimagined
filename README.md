# Tinex Studios Reimagined

Build a premium iGaming game-studio website for TINEX GAMES.

Use https://www.hacksawgaming.com/ as a structural and UX reference. Do not copy its branding, artwork, proprietary assets, text, or code.

Analyze the general design language:

 oversized cinematic hero

 dark premium game-studio aesthetic

 huge typography

 game artwork integrated heavily into layouts

 latest-games carousel/grid

 aggressive transitions and hover effects

 large full-width sections

 studio statistics

 game-category presentation

 individual game detail pages

 news/release section

 premium animated navigation

Reinterpret this as an original TINEX GAMES website.

Initial pages:

/

/games

/games/[slug]

/about

/contact

Homepage:

 Age verification overlay

 Full-screen Tinex Games hero

 Studio statistics

 Latest Games

 Featured Game

 What We Build

 Studio philosophy

 Latest releases/news

 Contact/partner CTA

 Premium footer

Game cards should use large artwork and contain:

 game title

 release status/date

 volatility

 max win

 game type

 Details button

 Play button when a playable URL exists

Make everything responsive and animation-heavy without hurting performance.

Use reusable React components and keep game content data-driven so adding another Tinex game only requires adding an object to a data file/database.
